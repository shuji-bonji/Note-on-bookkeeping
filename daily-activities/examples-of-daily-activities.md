# 日々やることの実践例

日次の簿記は「取引が発生した日に仕訳を起こし、証憑と突き合わせておく」ことが基本です。  
ここでは、借方・貸方の整理から代表的な仕訳例、減価償却の実務までをまとめました。

## 借方・貸方の要点おさらい

| 分類 | 借方で増える | 貸方で増える | 主な例 |
| --- | --- | --- | --- |
| 資産 | ✅ |  | 現金・預金・売掛金・備品 |
| 負債 |  | ✅ | 未払金・買掛金・借入金 |
| 純資産 |  | ✅ | 元入金・事業主借 |
| 収益 |  | ✅ | 売上高・受取利息 |
| 費用 | ✅ |  | 旅費交通費・通信費・減価償却費 |

借方・貸方は「左右のラベル」です。  
「どの勘定が増減したか？」を考えて、左右を決めるのがコツです。

> [!TIP]
> 仕訳を書く前に「どの勘定科目が動いたか」をメモしてから左右を決めると、迷いが減ります。

## よくある日次取引と仕訳

| 取引内容 | 借方 | 貸方 | ポイント |
| --- | --- | --- | --- |
| 現金で文房具を購入した | 消耗品費 | 現金 | 経費が発生し、現金が減少 |
| 仕事用モニターを口座振替で購入した（10万円未満） | 消耗品費 | 普通預金 | 少額なら費用処理が可能 |
| 仕事用モニターをクレジットで購入した（15万円） | 備品 | 未払金 | 資産を計上し、後日支払う義務が発生 |
| SaaS利用料をクレジットで支払った | 通信費 | 未払金 | 経費発生と未払金（負債）の発生 |
| クレジット代金が銀行口座から引き落とされた | 未払金 | 普通預金 | 未払金を消す |
| 外注費を請求書受領時に計上 | 外注費 | 未払金 | 発生主義で経費を計上 |
| 外注費を振込で支払った | 未払金 | 普通預金 | 負債の解消 |
| 取引先に請求書を発行した（後日入金） | 売掛金 | 売上高 | 収益の発生と債権の発生 |
| 売掛金が入金された | 普通預金 | 売掛金 | 債権の回収 |

> [!NOTE]
> クレジットカード利用時点では現金は動いていません。**未払金**で「支払義務」を記録し、引き落とし日に未払金を消します。

## ケーススタディ

### 1. クレジットカードでSaaSを契約

1. 利用料の計上  
   `借方: 通信費 / 貸方: 未払金`
2. 引き落とし時  
   `借方: 未払金 / 貸方: 普通預金`

### 2. 立替経費を清算

1. 従業員が立替えた交通費を精算  
   `借方: 旅費交通費 / 貸方: 未払金（従業員名）`
2. 給与と一緒に振込  
   `借方: 未払金（従業員名） / 貸方: 普通預金`

### 3. 日次で見逃しやすい仕訳

- **現金過不足**  
  現金出納帳と実際の現金残高が合わないときに一時的に使う勘定。月末には原因を特定して修正します。
- **仮払金・立替金**  
  目的が確定していない前払いや一時立替は仮払金で処理し、証憑が揃ったら正しい科目に振り替えます。
- **事業主貸・事業主借**  
  事業用口座から私的費用を払ったら事業主貸、私用資金を事業に入れたら事業主借で処理します。

## 減価償却の実務例

減価償却は「資産の価値を耐用年数で配分する」処理です。日次では以下のトリガーが発生します。

### 例1: パソコンを購入し、月次で減価償却

- 4月1日に 300,000円 の業務用PCを銀行振込で購入（耐用年数4年、定額法）
  - 取得時  
    `借方: 備品 300,000 / 貸方: 普通預金 300,000`
- 4月度の減価償却費  
  - 年間償却費: 300,000 ÷ 4年 = 75,000円  
  - 月次償却費: 75,000 ÷ 12 = 6,250円  
    `借方: 減価償却費 6,250 / 貸方: 減価償却累計額 6,250`

> [!TIP]
> 月次の償却仕訳は月末にまとめて入力します。会計ソフトの自動仕訳機能を使うと漏れを防げます。

### 例2: 償却途中の備品を売却した場合

- 取得: 2023年4月に 240,000円 の複合機を購入（耐用年数5年、定額法）
- 2024年9月末まで月次償却を計上  
  - 年額償却: 240,000 ÷ 5 = 48,000円  
  - 月額償却: 4,000円  
  - 償却済み累計（17か月分）: 4,000 × 17 = 68,000円
- 2024年10月に 120,000円 で売却し、入金は普通預金

仕訳の流れ:

1. 10月分の減価償却費  
   `借方: 減価償却費 4,000 / 貸方: 減価償却累計額 4,000`
2. 売却時に帳簿価額を消す  
   - 帳簿価額 = 240,000 − 72,000（累計） = 168,000円  
   - 売却仕訳  
     ```
     借方: 減価償却累計額 72,000
           現金預金 120,000
     貸方: 備品 240,000
     ```
3. 差額（168,000 − 120,000 = 48,000円）は売却損  
   `借方: 固定資産売却損 48,000 / 貸方: 現金預金 48,000`

> [!IMPORTANT]
> 売却時は「累計額で資産をゼロに戻し、売却代金との差額で損益を計上する」順序を守るとミスを防げます。

### 例3: 償却途中で廃棄した場合

1. 廃棄月まで減価償却費を計上  
2. 帳簿価額を「固定資産除却損」として処理  
   `借方: 固定資産除却損 / 借方: 減価償却累計額 / 貸方: 備品`

## 日次実務の進め方（テンプレ）

1. 当日の取引と証憑を確認する
2. 会計ソフトに仕訳入力（もしくは自動連携の承認）
3. 立替や未払はメモを残し、月次チェックリストに転記
4. 現金・預金・売掛・買掛の残高をざっくり確認
5. 不明な取引は証憑を保留フォルダに入れて翌日以降に対応

> [!TIP]
> 「不明取引は仮勘定で一次処理 → 月次で解消」というルールを作っておくと、日次処理が止まらなくなります。

## 練習問題

1. クレジットカードでオンライン広告費 55,000円（税抜）を支払った。消費税は仕入税額控除の対象。仕訳を考えてみましょう。
2. 取引先へ納品し、請求書を発行。金額は 220,000円。翌月末入金予定。仕訳は？
3. 取得価額 180,000円 の機械を月額 5,000円で減価償却中。償却累計額が 60,000円の時点で 100,000円で売却した場合の仕訳は？

> [!NOTE]
> 答え合わせは月次処理や年次処理のページで扱う予定です。自分の仕訳案をメモしておき、後で照合しましょう。
