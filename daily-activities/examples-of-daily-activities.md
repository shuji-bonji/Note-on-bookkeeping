> 💭 仕訳では「借方」と「貸方」に分けて書きますが、

> 借り方：借入金

> ？？？？

多くの人が最初にまさにそう思います。

> 「借りる」「貸す」＝お金をやり取りする、融資みたいな意味？

──でも、簿記の「借方」「貸方」は**日常の意味とは全く別の概念**なんです。


## 本当の意味：位置の名前（左右の概念）

簿記では、「借方」「貸方」は単に**左右を区別するためのラベル** です。

* 「借方（かりかた）」＝**左側に書く**
* 「貸方（かしかた）」＝**右側に書く**

それだけ。
「借りた」「貸した」ではありません。

### じゃあ何が左右で変わるの？

左右で「どういうときに増えるか」が変わります。
これが**簿記5要素** のルールです👇

| 要素 | 意味          | 増えるとき | 減るとき |
| -- | ----------- | ----- | ---- |
| 資産 | 現金・預金・売掛金など | 借方    | 貸方   |
| 負債 | 借入金・未払金など   | 貸方    | 借方   |
| 資本 | 元入金など       | 貸方    | 借方   |
| 収益 | 売上など        | 貸方    | 借方   |
| 費用 | 仕入・経費など     | 借方    | 貸方   |


#### たとえば、
「現金で文房具を買った」ならこうです👇

| 借方        | 貸方      | 内容    |
| --------- | ------- | ----- |
| 消耗品費（費用↑） | 現金（資産↓） | 経費の発生 |

→ 「費用は借方で増える」「資産は借方で増える」ルールに従っています。


ここまでで1つ確認してみましょう👇

> 💭 「現金で仕事用のモニターを買った」とき、
> 借方と貸方はどんな科目になると思いますか？

> 借り方 | 貸方 | 内容
> ---|---|---
> 資産（消耗品）| 現金 | 経費の発生 

おお、かなり正解に近いです👏

ただ、**2点だけ微調整**しましょう。
これはとても良いタイミングで学べる部分です。


## 正しい仕訳例（モニター購入）

| 借方              | 貸方     | 内容         |
| --------------- | ------ | ---------- |
| **備品（または消耗品費）** | **現金** | 業務用モニターを購入 |


### 補足解説

* 「モニター」は**事業で使う資産** です。
* 10万円未満なら「消耗品費（費用）」扱いでもOK。
* 10万円以上なら「備品（資産）」として**減価償却** の対象になります。

### この取引が意味すること

* **借方：備品（資産が増える）**
* **貸方：現金（資産が減る）**
* 結果として「資産がモノからお金に変わっただけ」＝**資産内の振り替え** 。


つまりこの仕訳では

> 💬 「資産が増え、別の資産が減った」
> という取引なんですね。

## クレジット支払いの本質

> クレジット会社があなたの代わりにお金を立て替えた
> → つまり「**一時的な借金**」が発生した

はい、その通りです。
ただし、この「借金」は銀行からの長期借入ではないため、勘定科目は **借入金** ではなく
👉 **未払金（みはらいきん）** を使います。


### 「借入金」と「未払金」の違い

| 勘定科目    | 意味                   | 例               |
| ------- | -------------------- | --------------- |
| **借入金** | 銀行などから**資金を借りた**（融資） | 事業資金・ローンなど      |
| **未払金** | 商品やサービスを**後払いで買った**  | クレジット購入・請求書払いなど |

### つまり仕訳の構造はこうです。

| 借方        | 貸方  | 内容             |
| --------- | --- | -------------- |
| 経費（通信費など） | 未払金 | クレカ立替により支払義務発生 |

この瞬間、「経費が発生した」と認識しつつ、まだ現金は動いていません。
だから青色申告の**発生主義** でしっかり経費に計上できるのです。


#### まとめると

> * クレカ払い＝未払金が増える（短期の借金）
> * 銀行借入＝借入金が増える（長期の借金）


まさにここが「実務簿記」と「仕訳簿記」の境目なんです。


## 定義の違い（公式な考え方）

| 勘定科目            | 定義（会計的な意味）                      | 発生の相手先                | 支払期日・期間         | 主な例                      |
| --------------- | ------------------------------- | --------------------- | --------------- | ------------------------ |
| **借入金（かりいれきん）** | 金銭そのものを**借りた**取引。返済義務がある。       | 銀行・信用金庫・金融機関・親族・取引先など | 通常は中長期（1年以上が多い） | 銀行融資、運転資金、設備資金など         |
| **未払金（みはらいきん）** | 商品やサービスを**後払いで買った**取引。支払い義務がある。 | 仕入先・サービス提供者・クレジット会社など | 短期（1か月～数か月）     | クレカ利用、請求書払い、税理士報酬、備品購入など |

### つまり

* 「借入金」＝**お金そのもの**を借りた
* 「未払金」＝**モノやサービス**を買って、まだ払っていない


### さらに細かい区分もあります

実務では「短期借入金」「長期借入金」と分けることもあります：

| 科目名       | 内容                  |
| --------- | ------------------- |
| **短期借入金** | 1年以内に返すお金（つなぎ資金など）  |
| **長期借入金** | 1年以上かけて返すお金（設備投資など） |


#### まとめると

> クレジットカードや請求書払い → **未払金**
> 銀行・金融機関・知人から資金を借りた → **借入金**

## リボ払い（分割払い）の扱いは、ちょうど中間

あなたの言うように、クレジットカードのリボ払いや分割払いは
「**未払金**と**借入金** の中間的な存在」です。

なぜなら：

| 仕訳上の分類                           | 理由                          |
| -------------------------------- | --------------------------- |
| ✅ 最初の購入時 → **未払金**               | まだ“商品やサービス”の対価を支払っていないだけだから |
| ✅ 支払いが複数回（長期）にわたる → **借入金** に近い扱い | 実質的に「お金を借りて返済している」状態になる     |


### 実務での扱い方

1. **購入時**
   　→ 通常どおり「未払金」で処理します。
   　（例）Office365をリボ払いに設定
   　`text
   　借方：通信費　／　貸方：未払金
   　`

2. **支払明細が出た段階で、利息（手数料）が含まれていれば**
   　→ その利息部分だけを「支払利息」として経費計上します。
   　（例）リボ手数料500円
   　`text
   　借方：支払利息　／　貸方：未払金
   　`

3. **毎月の引き落とし時**
   　→ 「未払金（または借入金）」を減らし、「普通預金」を減らす仕訳
   　`text
   　借方：未払金　／　貸方：普通預金
   　`

#### つまり

> * 商品購入 → 未払金
> * リボ払いの利息 → 支払利息（経費）
> * 実際の返済 → 未払金や借入金の減少


この流れを理解できていれば、日次の経理処理はかなり完成度が高いです。

## 取引内容

> エージェントから報酬（業務委託の入金）があった


### 正しい仕訳

| 借方       | 貸方      | 内容           |
| -------- | ------- | ------------ |
| **普通預金** | **売上高** | 業務委託報酬の入金を確認 |


### 解説

* **借方（左）＝資産が増える** → 銀行口座にお金が入った
* **貸方（右）＝収益が増える** → 仕事の対価（売上）が発生した

つまり、

> 💡「銀行残高が増えた＝資産の増加」
> 💡「報酬を得た＝収益の増加」

この2つを**発生主義の原則** で記録するわけです。


### 🔹 注意：報酬という勘定科目

* 「報酬」という名前の科目は通常は使いません（それは**あなたが払う側** のとき＝外注費や給与報酬など）
* あなたが **もらう側** なら、正しくは「売上高（収益）」です。

| 状況         | 借方   | 貸方  |
| ---------- | ---- | --- |
| 請求書発行（入金前） | 売掛金  | 売上高 |
| 入金時        | 普通預金 | 売掛金 |

| ---- | --- | ------------ |

## 正解は：**「発生している」けど、まだ請求していない売上**

たしかに「請求してない＝まだ確定してない感じ」がしますが、
簿記ではもう少し厳密に考えます。

> 仕事（サービス・納品）が完了した時点で、**取引は発生している**
> 請求書は単なる“通知書”にすぎません。


### 簿記的な考え方（発生主義）

| 状況      | 取引発生？ | 理由                |
| ------- | ----- | ----------------- |
| 納品・業務完了 | ✅ 発生  | 経済的価値（報酬請求権）が確定した |
| 請求書未発行  | ✅ 発生済 | 書類上の手続きがまだなだけ     |
| 入金未確認   | ✅ 発生済 | まだ現金化されていないだけ     |


### このときの仕訳（仮に3月末に業務完了して未請求）

| 借方  | 貸方  | 内容                  |
| --- | --- | ------------------- |
| 売掛金 | 売上高 | 3月の業務完了分。請求書は翌月発行予定 |

これを入れておくことで、
**3月の売上に正しく反映** され、損益計算書の精度が上がります。


#### まとめ

> 💬 仕事が終わった時点で売上発生。
> 請求書はその証拠であって、発生のトリガーではない。

> 個人事業主の生活費として引き出したお金は？

とても実務的で、まさに個人事業主ならではの鋭い質問です💡
──この「生活費の引き出し」は、簿記的にも重要なテーマなんです。


## 結論から言うと

> ✅ **「事業主貸（じぎょうぬしかし）」** という勘定科目で処理します。

### 仕訳の形

> 💭 たとえば事業用口座から10万円を引き出して生活費にした場合

| 借方       | 貸方       | 内容               |
| -------- | -------- | ---------------- |
| **事業主貸** | **普通預金** | 生活費として事業資金を引き出した |


### 解説

* **「事業主貸」** は「個人の生活費など、事業とは関係のない出金」を表す勘定科目です。
* 経費ではありません。
* 税務的には「自分のお金を自分で使っただけ」なので、損益計算書には影響しません。


## 逆に「個人のお金を事業に入れた」場合は？

このときは反対の科目になります👇

| 借方       | 貸方       | 内容              |
| -------- | -------- | --------------- |
| **普通預金** | **事業主借** | 生活資金から事業資金に充当した |


### つまり

| 行動             | 借方   | 貸方   |
| -------------- | ---- | ---- |
| 生活費として引き出す     | 事業主貸 | 普通預金 |
| 自分の財布から事業に入金する | 普通預金 | 事業主借 |

#### まとめ

> 「事業主貸」＝**事業から個人へ出すお金**
> 「事業主借」＝**個人から事業へ入れるお金**

この2つは、個人事業主だけの特別な科目です。
法人（会社）では使いません。

ここで確認です👇
あなたの運用では、「事業専用口座」と「個人用口座」は分けていますか？
（どちらで管理しているかによって、仕訳の整理方法が変わります）

> 今まで使っていた個人のいくつかの口座のうちの1つを事業用として使うことにした。

そしてその運用、**簿記的にもまったく問題ありません。**
「私用口座を事業専用として使い始める」──これは個人事業主の最初の一歩として自然な形です。


## まず前提

あなたの場合、

> 「個人口座を“事業専用口座”として使い始めた」＝
> 事業をスタートするために自分の資金を事業に“入れた”状態です。

簿記上では、これは**“事業主借”の発生**として記録します👇

### 開業時の最初の仕訳（例）

| 借方   | 貸方   | 内容                  |
| ---- | ---- | ------------------- |
| 普通預金 | 事業主借 | 自己資金を事業用口座に入金して開業準備 |

> 💬 「自分のお金を、事業に貸した」扱い。
> この“貸した”という表現は、あくまで会計上の区別のためです。

### その後のイメージ

| 状況             | 借方   | 貸方   | 説明         |
| -------------- | ---- | ---- | ---------- |
| 売上の入金          | 普通預金 | 売上高  | 収益発生       |
| 経費支払い          | 経費科目 | 普通預金 | 支出         |
| 生活費引き出し        | 事業主貸 | 普通預金 | 個人利用分の引き出し |
| 追加で自分の財布から資金投入 | 普通預金 | 事業主借 | 事業資金の補充    |

### ポイントまとめ

* 「事業主借」＝自分の財布から事業に**入れたお金**
* 「事業主貸」＝事業から自分に**引き出したお金**
* この2つは「資産と負債の入出」だけで、**損益には影響しません**。
* 開業直後は「事業主借」から始まり、「事業主貸」で生活費を出す流れが自然。

> 💭 あなたが購入したモニターが「8万円」だったとして、
> これは「経費（消耗品費）」にしてもいいと思いますか？
> それとも「固定資産（備品）」にすべきでしょうか？

その感覚、めちゃくちゃ良いです👏
そして実務的にも**すごく正しい迷い方**です。
実際、ここは**金額と使用期間の両方**で判断されます。


## 原則：金額で線を引く

税法上は次のルールがあります👇

| 区分               | 処理方法           | 条件・金額                             | 補足             |
| ---------------- | -------------- | --------------------------------- | -------------- |
| **消耗品費（経費）**     | 一括で経費にできる      | 取得価額が **10万円未満**                  | 使用期間に関係なく即経費OK |
| **少額減価償却資産（特例）** | 一括で経費にできる      | 青色申告者なら **30万円未満までOK（年間300万円まで）** | 「中小企業者等の特例」    |
| **固定資産（備品）**     | 減価償却で数年に分けて経費化 | 10万円以上（または特例超過）                   | 使用年数に応じて按分     |


### あなたのモニター（8万円）なら？

→ ✅ **消耗品費で即経費OK**
10万円未満だから、償却の必要なし。
ただし、もし本体＋スタンドなど合計で10万円を超えるなら、「備品（資産）」扱いにします。

### 使う期間は考慮しないの？

実務では「長く使うものは資産」と言いたくなりますが、
税法上は**原則金額ベース**です。
つまり「3〜4年使う」ことは関係ありません。

> 💡 少額（10万円未満）なら“たとえ5年使っても”経費でOK。


### まとめ

> * 10万円未満 → 消耗品費
> * 10〜30万円未満 → 少額減価償却資産（青色なら一括OK）
> * 30万円以上 → 備品（減価償却）
