# 日々やること

## 日々の簿記の目的

> 「今日のお金の動きを、正確に記録しておくこと」

会計の世界ではこれを「**取引の記録（仕訳）**」と呼びます。
1件の取引を、「**いつ／何を／いくら／どの科目で**」記録するのが基本です。

## 日々やる5つの作業（個人事業主向け）

| 項目           | 内容                      | 目的           |
| ------------ | ----------------------- | ------------ |
| ① 取引の記録      | 売上・仕入・経費・入出金を帳簿（ソフト）に入力 | 後で集計できるようにする |
| ② 領収書・請求書の整理 | 紙・PDF・メールを日付順や科目別に整理    | 根拠資料を残す      |
| ③ 売上・経費の確認   | クレカ・口座・現金の動きをチェック       | 記帳漏れを防ぐ      |
| ④ 残高照合       | 通帳の金額と帳簿の金額を照らす         | 食い違いを早期発見    |
| ⑤ 修正とメモ      | 不明点や未確定取引にメモを残す         | 月末集計がスムーズに   |


## 例えば・・・・

- 仕事に必要なPCに接続するためのモニターを購入
- Office365のサブスクの領収書を記録
- エージェントからの発注金額の確認
- エージェントからの入金確認
- クレジットからの引き落とし確認

この5項目は、すべて**日々の簿記で扱う「取引の記録」と確認」** に該当します。
では次のステップとして、それぞれを**簿記の形式（＝仕訳）** で見てみましょう。


## あなたの例を簿記形式に直すとこうなります。

| 内容                | 勘定科目（借方）                  | 勘定科目（貸方）          | 補足                 |
| ----------------- | ------------------------- | ----------------- | ------------------ |
| PC作業用モニターを購入（業務用） | **備品**                    | **現金／普通預金／クレジット** | 10万円未満なら「消耗品費」扱いも可 |
| Office365のサブスク支払い | **通信費** または **ソフトウェア使用料** | **クレジット**         | 毎月支払いなら定期費用        |
| エージェント発注金額（請求書受領） | **売掛金**                   | **売上高**           | 発注段階ではまだ入金されていない   |
| エージェントからの入金確認     | **普通預金**                  | **売掛金**           | 売掛金の回収（入金）         |
| クレジット引き落とし確認      | **未払金**                   | **普通預金**          | クレジット明細と照合して処理     |

### ポイント

* 簿記では「何を得たか（借方）」と「何を失ったか（貸方）」で1件の取引を表します。
* この1行（または2行）が「**仕訳（journal entry）**」です。
* これを毎日、発生ベースで記録していくのが日次簿記です。

## 
> 「仕訳」は簿記の最小単位ですが、実務では**どのタイミングで記録する** のが良いと思いますか？
> 例：
>
> * 取引が発生した瞬間
> * 請求書を受け取ったとき
> * 支払い（または入金）したとき

どのタイミングで記帳すればいいと感じますか？

> A: 
> そう、「**取引**」という言葉が簿記の核心です。
> では、少し深堀りしてみましょう。

## まず定義から

簿記でいう「取引」とは

> **お金の増減（資産・負債・資本・収益・費用）が発生する経済活動**
> のことです。

つまり、
「現金・預金・売掛金・経費・売上」など、
**お金に換算できる動きがあった瞬間**が「取引の発生」です。


###  具体例で比較

| 事象                     | 簿記上の扱い      | 理由              |
| ---------------------- | ----------- | --------------- |
| モニターを注文した（まだ届いていない・未払） | 取引 **ではない** | お金や物がまだ動いていない   |
| モニターを受け取り、支払いを行った      | ✅ **取引発生**  | 資産（備品）と現金の交換が発生 |
| Office365の請求書を受け取った    | ✅ **取引発生**  | 使用料（費用）と未払金が発生  |
| 入金予定を連絡された（まだ入金なし）     | 取引 **ではない** | 実際の資産変動がまだない    |
| 銀行口座に入金があった            | ✅ **取引発生**  | 売掛金の回収＝資産の変化    |


つまり、前で挙げたような項目の中では
**「お金またはサービスが実際に動いた時点」** が、仕訳の対象＝記録すべきタイミングです。


## 次のステップとして質問です👇

> あなたの例の中で、「発注金額の確認」と「入金確認」がありました。
> どちらが「取引発生」になると思いますか？
> （理由も一文で構いません）

入金確認は実際に現金が振り込まれてるから、取引発生
発注金額については？


> ✅ 入金確認 → 現金（資産）が実際に増える → 「取引発生」
> まさにその通りです。

では、続けて「発注金額」の扱いを見てみましょう👇


###  「発注金額の確認」はまだ取引ではない

なぜなら──
発注とは **「これから仕事（またはサービス）をします」という約束の段階** だからです。
まだお金もモノも動いていません。

ただし、次の2つのケースで意味が変わります。

| 状況                    | 簿記上の扱い   | 理由                    |
| --------------------- | -------- | --------------------- |
| ① まだ仕事をしていない（見積・契約段階） | ❌ 取引ではない | 経済価値の移転が起きていない        |
| ② 仕事を完了し、請求書を発行した     | ✅ 取引発生   | 売上高（収益）と売掛金（資産）が同時に発生 |


つまり、あなたが**エージェントから発注を受けて、その仕事を納品した段階** で
簿記上の「取引」が発生します。
その時点で次のような**仕訳** になります👇

| 借方  | 貸方  | 内容               |
| --- | --- | ---------------- |
| 売掛金 | 売上高 | 納品完了・請求書発行時（入金前） |

### ここまでの流れをまとめると：

> **取引が発生するのは、モノ・サービス・お金が実際に動いた時。**
> 「発注」ではまだ約束の段階。
> 「請求」または「入金」で初めて記録する。

ここで確認したいのですが、
あなたは実際の帳簿（aoiro.appなど）では、**請求書発行の時点**で記録したいですか？
それとも、**入金があった時点**でまとめて記録する方が現実的と感じますか？

> どちらでもいいのですか？

とても良い質問です。
実はここが簿記の考え方で**最も重要な分かれ道** なんです。


## 結論：どちらでもOK、ただし方式が違う

| 会計方式           | 記録のタイミング                  | 主な対象者                 | 特徴                 |
| -------------- | ------------------------- | --------------------- | ------------------ |
| **発生主義（複式簿記）** | 取引が**発生した時点**（請求書発行・納品など） | 青色申告（65万円控除）を目指す個人事業主 | 正確。売掛金・未払金なども記録する。 |
| **現金主義（簡易簿記）** | お金が**実際に動いた時点**（入金・出金）    | 白色申告・小規模な副業           | シンプル。入出金だけ記録。      |

### 例で比べる

| 取引内容        | 発生主義での記録     | 現金主義での記録     |
| ----------- | ------------ | ------------ |
| 納品して請求書を出した | 借：売掛金／貸：売上高  | （まだ記録しない）    |
| 入金された       | 借：普通預金／貸：売掛金 | 借：普通預金／貸：売上高 |


### つまり

> 「どちらでもいい」けれど、
> 一度どちらかの方式で帳簿をつけ始めたら、**1年間は統一する必要があります。**

青色申告で65万円控除を狙うなら「発生主義（複式簿記）」が必須です。
aoiro.app もこの方式で動いています。


> 💼 **青色申告（65万円控除）＝発生主義・複式簿記で帳簿をつける**

これにより、あなたは個人事業主として「本格的な会計の仕組み」を理解・運用する立場になります。
ここから先は「取引を仕訳で記録する」ことが毎日の基本になります。


## 日々やること（青色申告向け）のまとめ

| 区分               | やること              | 簿記上の意味     |
| ---------------- | ----------------- | ---------- |
| ① 取引の発生を把握       | 売上・仕入・経費・入出金などを確認 | 会計データの材料   |
| ② 仕訳をする          | 「借方」「貸方」に分けて入力    | 取引を記録する    |
| ③ 証憑（領収書・請求書）を整理 | 取引の証拠として保管        | 税務上の根拠資料   |
| ④ 残高確認           | 銀行・クレカ・現金の照合      | 記帳漏れの防止    |
| ⑤ メモ・分類          | 不明な取引は保留メモを残す     | 月末処理をスムーズに |
