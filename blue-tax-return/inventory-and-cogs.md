# 棚卸と売上原価（仕入三分法まとめ）

期末棚卸は、**売上原価を正しく計算するための決算整理**です。
物販や在庫を持つ事業では必須ですが、受託開発など在庫のない業種では不要なケースもあります。

> [!TIP]
> サービス業で棚卸資産がない場合は、このページの「売上原価の計算」はスキップして構いません。

## 目的（ここでやること）

- 期末棚卸高を確定する
- 売上原価を計算する
- 仕入三分法の期末振替仕訳を行う

## 期末棚卸のチェックリスト

```
□ 期末棚卸日を決める（通常は12/31）
□ 商品・材料の数量を数える
□ 単価を確定する（原価の算定方法を統一）
□ 棚卸表を作成する（数量×単価）
□ 期末棚卸高を計算する
□ 期末振替仕訳を行う
```

## 売上原価の基本式

```
売上原価 ＝ 期首棚卸高 + 当期仕入高 − 期末棚卸高
```

| 用語 | 意味 |
|:-----|:-----|
| 期首棚卸高 | 期首時点の在庫の評価額（繰越商品） |
| 当期仕入高 | 期中の仕入合計（仕入） |
| 期末棚卸高 | 期末時点の在庫の評価額（繰越商品） |

## 仕入三分法（期末の振替ルール）

仕入三分法では、期中は「仕入」勘定だけを使い、**期末に在庫（繰越商品）へ振替**します。

1. 期首の繰越商品を仕入へ振替
2. 期末の繰越商品を仕入から戻す
3. 仕入勘定の残高が売上原価になる

> [!NOTE]
> 繰越商品は「資産」です。期末に在庫が残っていれば、費用（仕入）を減らす仕訳になります。

## 数値例（期末棚卸あり）

前提：

- 期首繰越商品：120,000円
- 当期仕入高：900,000円
- 期末棚卸高：80,000円

```
売上原価 ＝ 120,000 + 900,000 − 80,000 ＝ 940,000円
```

### 期首分を仕入に振替

| 借方 | 金額 | 貸方 | 金額 |
|:-----|-----:|:-----|-----:|
| 仕入 | 120,000 | 繰越商品 | 120,000 |

### 期末分を繰越商品に振替

| 借方 | 金額 | 貸方 | 金額 |
|:-----|-----:|:-----|-----:|
| 繰越商品 | 80,000 | 仕入 | 80,000 |

この2つの仕訳の結果、**仕入勘定の残高が 940,000円**となり、損益計算書の売上原価になります。

## 棚卸表（ミニ例）

| 商品 | 数量 | 単価 | 金額 |
|:-----|-----:|-----:|-----:|
| 商品A | 10 | 3,000 | 30,000 |
| 商品B | 5 | 10,000 | 50,000 |
| 合計 |  |  | 80,000 |

> [!IMPORTANT]
> 単価の算定方法（先入先出法・総平均法など）は**年を通して一貫**させます。
