# 青色申告で必要な帳簿

以下は、**青色申告で必要な帳簿とその用途・役割の一覧**です。
青色申告は「複式簿記」を前提とするため、**取引を二面的に記録（原因と結果）**するのが特徴です。

## 基本帳簿（複式簿記の中核）

| 帳簿名       | 用途・役割                                                                  |
| :-------- | :--------------------------------------------------------------------- |
| **仕訳帳**   | 全ての取引を日付順に「借方」「貸方」に分けて記録する帳簿。すべての取引の起点となる。取引の発生順に記録する。                 |
| **総勘定元帳** | 仕訳帳の内容を科目ごとにまとめた帳簿。各勘定科目（現金、売掛金、経費など）の増減が一目で分かる。決算書（損益計算書・貸借対照表）の元データ。 |

## 資金の流れを把握する帳簿

| 帳簿名       | 用途・役割                                   |
| :-------- | :-------------------------------------- |
| **現金出納帳** | 現金の出入りを記録する。現金残高が実際の現金と一致しているか確認する。     |
| **預金出納帳** | 銀行口座の入出金を記録する。通帳と一致しているかを確認する。          |
| **手形記入帳** | 受取手形・支払手形の発行・期日・決済などを記録する。手形取引がある事業で必要。 |

## 売上・仕入に関する帳簿

| 帳簿名         | 用途・役割                                        |
| :---------- | :------------------------------------------- |
| **売掛帳**     | 掛け販売の内容を取引先別に記録。未回収金や入金状況を把握する。              |
| **買掛帳**     | 掛け仕入の内容を取引先別に記録。支払予定を把握する。                   |
| **債権債務記入帳** | 売掛金・買掛金など、取引先ごとの債権・債務を一覧で管理する。売掛・買掛帳を統合した形式。 |

## 経費や資産を管理する帳簿

| 帳簿名        | 用途・役割                                                     |
| :--------- | :-------------------------------------------------------- |
| **経費帳**    | 経費を科目別（日付・支出先・金額など）に記録。仕訳帳の補助帳として使われる。                    |
| **固定資産台帳** | パソコン・机・車などの減価償却資産を管理。取得日、金額、耐用年数、償却方法などを記載。決算時の減価償却計算に使用。 |

## 伝票による記録方式（伝票会計を採用する場合）

| 伝票名                                        | 用途・役割                            |
| :----------------------------------------- | :------------------------------- |
| **入金伝票**                                   | 売上や回収など、現金・預金が入った取引を記録。          |
| **出金伝票**                                   | 仕入や経費支払いなど、現金・預金が出た取引を記録。        |
| **振替伝票**                                   | 現金の出入りを伴わない取引（例：売掛金の発生、減価償却）を記録。 |

> [!NOTE] **補足：** 伝票方式ではこれらをもとに後で仕訳帳・総勘定元帳に転記します。

## 簡易簿記・現金主義を採る場合（10万円控除）

| 帳簿名         | 用途・役割                                                                    |
| :---------- | :----------------------------------------------------------------------- |
| **現金式簡易帳簿** | 現金の出入りだけを記録する簡易帳簿。発生主義ではなく、現金主義（入出金ベース）で記録する。売掛・買掛は記録不要。白色申告や10万円控除で使用可。 |

## その他・補助的帳簿

| 帳簿名        | 用途・役割                             |
| :--------- | :-------------------------------- |
| **仕入帳**    | 商品・材料などの仕入内容を日付順に記録。              |
| **売上帳**    | 商品やサービスの売上内容を日付順に記録。              |
| **旅費交通費帳** | 出張や交通費などを明細付きで記録。領収書と突合するための補助帳簿。 |
| **小口現金帳**  | 少額の経費支払い（コピー代、切手代など）を管理する帳簿。      |
| **給与台帳**   | 従業員や家族従業者への給与・源泉徴収税額を記録。          |

## 青色申告での帳簿分類まとめ（必須・推奨）

| 区分   | 帳簿名                            | 必要度            |
| :--- | :----------------------------- | :------------- |
| 基本帳簿 | 仕訳帳、総勘定元帳                      | ⭐必須（65万円控除対象）  |
| 補助帳簿 | 現金出納帳、預金出納帳、売掛帳、買掛帳、経費帳、固定資産台帳 | ⭐推奨（証拠力を補強）    |
| 任意帳簿 | 手形記入帳、債権債務記入帳、旅費交通費帳など         | ◯必要に応じて        |
| 伝票   | 入金伝票、出金伝票、振替伝票                 | ◯伝票会計方式を取る場合のみ |
| 簡易帳簿 | 現金式簡易帳簿                        | △10万円控除や白色申告向け |
