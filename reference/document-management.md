# 証憑管理（電子帳簿保存法対応の基本）

証憑管理は、**仕訳の裏付けを残し、税務上の説明責任を果たすための基盤**です。
このページでは、個人事業主が最低限押さえる証憑の集め方・命名・保存ルールをまとめます。

## 目的（ここでやること）

- 証憑を漏れなく集める
- 電子帳簿保存法に沿って検索できる形で保存する
- 仕訳と証憑を紐付けられる状態にする

## 証憑の種類（最低限）

| 種類 | 例 | 備考 |
|:-----|:----|:-----|
| 収入系 | 請求書、入金明細 | 入金が分かる資料も保管 |
| 支出系 | 領収書、請求書、レシート | 支払方法が分かると良い |
| 決済明細 | 銀行・クレジット明細 | 照合用として重要 |
| 契約系 | 業務委託契約、利用規約 | 取引の根拠資料 |

## 電子保存の最低要件（概要）

電子帳簿保存法では、**検索できる状態での保存**が必要です。
運用としては、ファイル名とフォルダ構成で「検索キー」を表現します。

検索キーの例：

- 取引日
- 取引先
- 金額

> [!NOTE]
> 保存要件は制度改正で変わります。使用中の会計アプリやクラウドサービスの案内に従うのが安全です。

## ファイル命名ルール（テンプレ）

```
YYYYMMDD_取引先_内容_金額_支払方法
```

| 例 | 説明 |
|:----|:-----|
| `20240412_ABC-Corp_DesignFee_120000_Bank.pdf` | 請求書（入金） |
| `20240508_Amazon_PC-Parts_45600_Card.jpg` | 仕入（カード） |
| `20240630_Sakura-Internet_Server_11000_Transfer.pdf` | サーバー費用 |

> [!IMPORTANT]
> 日本語を使う場合も、**日付・取引先・金額が一目で分かる命名**にします。検索性が最優先です。

## フォルダ構成（例）

```
/evidence
  /2024
    /2024-01
    /2024-02
  /2025
    /2025-01
```

- 月次で分けると突合しやすい
- 取引が多い場合は「収入/支出」で分けてもOK

## 証憑と仕訳の紐付け

- 証憑ファイル名に取引内容を入れておく
- 会計アプリの仕訳に証憑を添付する
- 同じID（連番）を使って相互参照できるようにする

## 保存年限（基本）

- 帳簿・証憑は**原則7年保存**
- 青色申告の場合、帳簿の種類により10年保存が求められることもある

> [!NOTE]
> 具体的な保存年限は帳簿の種類や状況で変わります。迷ったら7年より長く保存する方が安全です。
