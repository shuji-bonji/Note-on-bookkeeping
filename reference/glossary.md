# 用語集（簿記・青色申告・消費税）

簿記3級レベルと個人事業主の実務で頻出する用語を、短く整理します。

> [!TIP]
> 迷いやすい用語は「似ている語の違い」を見比べるのが近道です。

## 会計の基本

| 用語 | 意味 |
|:-----|:-----|
| 資産 | 現金・預金・売掛金・備品など「将来の経済的価値」 |
| 負債 | 未払金・借入金など「将来支払う義務」 |
| 純資産（資本） | 資産−負債（事業主の持ち分） |
| 収益 | 売上・受取手数料など、利益を増やす取引 |
| 費用 | 仕入・経費など、利益を減らす取引 |
| 損益計算書（P/L） | 期間の収益・費用・利益を示す表 |
| 貸借対照表（B/S） | 期末時点の資産・負債・純資産を示す表 |

## 仕訳・帳簿

| 用語 | 意味 |
|:-----|:-----|
| 仕訳 | 取引を借方・貸方に分解して記録すること |
| 借方 / 貸方 | 仕訳の左右。増減は勘定科目の性質で決まる |
| 勘定科目 | 取引を分類する名前（例：売上、通信費） |
| 総勘定元帳 | 仕訳を勘定科目ごとに集計した帳簿 |
| 補助簿 | 現金出納帳や売掛帳など、詳細を記録する帳簿 |
| 試算表 | 期中の残高・合計を一覧化した確認表 |

## 売掛・買掛・未払・前払

| 用語 | 意味 |
|:-----|:-----|
| 売掛金 | 売上は立ったが、まだ入金されていない金額 |
| 買掛金 | 仕入は済んだが、まだ支払っていない金額 |
| 未収入金 | 役務提供以外の未入金（固定資産売却など） |
| 未払金 | 役務提供以外の未払い（備品購入など） |
| 未払費用 | サービスは受けたが、支払が翌期になる費用 |
| 前払費用 | 翌期分のサービスを当期に支払った費用 |
| 前受金 | 先に受け取った代金（サービス提供はこれから） |
| 仮払金 | 内容が未確定の支出（精算前の立替など） |
| 仮受金 | 内容が未確定の入金（用途不明の入金） |

> [!NOTE]
> 売掛金・買掛金は「本業の取引」に使うのが原則です。固定資産の売買などは未収入金・未払金を使います。

## 決算整理

| 用語 | 意味 |
|:-----|:-----|
| 減価償却 | 固定資産の取得価額を耐用年数で分割計上 |
| 減価償却費 | 当期に費用化する償却額 |
| 棚卸資産 | 期末時点で残っている商品・材料 |
| 繰越商品 | 棚卸資産を表す勘定科目（商品在庫） |
| 売上原価 | 期首棚卸＋仕入−期末棚卸 |
| 家事按分 | 事業と私用を合理的に分ける処理 |
| 貸倒引当金 | 売掛金の回収不能リスクに備える引当 |

## 税金・申告

| 用語 | 意味 |
|:-----|:-----|
| 青色申告 | 65万円（または55万円）の控除が使える申告方式 |
| 白色申告 | 簡易な記帳で申告する方式 |
| 青色申告決算書 | 青色申告で提出する損益計算書・貸借対照表 |
| 確定申告書B | 事業所得を申告するための主な申告書 |
| 控除 | 課税対象となる所得を減らす仕組み |
| 課税 | 税金がかかる取引 |
| 免税 | 税金がかからない取引 |
| 非課税 | 消費税の対象外となる取引 |

## 消費税

| 用語 | 意味 |
|:-----|:-----|
| 課税事業者 | 消費税を納める義務がある事業者 |
| 免税事業者 | 消費税の納税義務がない事業者 |
| 仕入税額控除 | 仕入や経費に含まれる消費税を控除する仕組み |
| 税込経理 | 税込の金額で仕訳する方式 |
| 税抜経理 | 税抜金額と消費税を分けて仕訳する方式 |
| インボイス | 適格請求書。仕入税額控除に必要 |
