# 仕訳の基礎と典型パターン

日々の実務や演習に入る前に、「仕訳のルール」と「よくある型（パターン）」を整理します。簿記3級レベルの学習・実務の土台です。

## 仕訳の基本ルール

- 取引は必ず「借方（左）」「貸方（右）」の2側面で記録する（複式簿記）
- 金額は左右で必ず一致する
- 左右の決め方は「どの勘定が増減したか？」で判断する

> [!TIP]
> 借方で増えるのは「資産・費用」、貸方で増えるのは「負債・純資産・収益」。

## 記録の前提（発生主義）

- 本プロジェクトは青色申告（複式簿記）を前提に「発生主義」で記録します。
- 発生主義：モノ・サービスの提供や受領、請求のタイミングで記録（入出金の有無は問わない）
- 現金主義：入出金のタイミングで記録（参考：簡易簿記・白色申告）

## 三分法（仕入・売上の基本）

商品売買の処理を「仕入」「売上」「繰越商品（棚卸）」の3つに分けて記録する方法です。

### 期中の基本仕訳

| 取引 | 借方 | 貸方 | メモ |
| --- | --- | --- | --- |
| 商品を掛で仕入 | 仕入 | 買掛金 | 仕入＝費用（期中は費用で処理） |
| 現金で仕入 | 仕入 | 現金 |  |
| 掛で販売 | 売掛金 | 売上 | 収益の計上と債権の発生 |
| 現金で販売 | 現金 | 売上 |  |
| 返品・値引（仕入側） | 買掛金（または現金） | 仕入 | 仕入の減少 |
| 返品・値引（売上側） | 売上 | 売掛金（または現金） | 売上の減少 |

### 期末棚卸と期首振替（重要）

- 期末に実地棚卸を行い、在庫（繰越商品）を計上します。
- 期首には前期末の繰越商品を仕入に振り替えます。

期末（在庫計上）

```
借方: 繰越商品 / 貸方: 仕入
```

期首（在庫振替）

```
借方: 仕入 / 貸方: 繰越商品
```

> [!NOTE]
> 三分法では、期中は「仕入＝費用」で計上し、期末に在庫分を費用から除外して当期の売上原価を確定します。

## 債権・債務の整理

- 売掛金：販売したが未回収の金額（資産）
- 買掛金：仕入れたが未払いの金額（負債）
- 未収入金・未払金：商品売買以外での債権・債務
- 前受金・前払金：受領・支払が先行した場合の調整勘定

代表パターン：

```
（請求時）   借方: 売掛金 / 貸方: 売上
（入金時）   借方: 普通預金 / 貸方: 売掛金
（請求受領） 借方: 仕入（または経費） / 貸方: 買掛金・未払金
（支払時）   借方: 買掛金・未払金 / 貸方: 普通預金
```

## クレジットカード・立替・仮勘定

- クレジット利用時は「未払金」で記録、引落日に未払金を消す
- 目的未確定の支払は「仮払金」で一時処理、確定後に振替
- 個人と事業の資金移動は「事業主借・事業主貸」で処理

## 固定資産と減価償却

- 10万円以上の耐久資産は資産計上し、耐用年数で配分（減価償却）
- 取得：`借方: 備品等 / 貸方: 現金・預金・未払金`
- 月次償却：`借方: 減価償却費 / 貸方: 減価償却累計額`
- 売却：`借方: 減価償却累計額・現金・売却損(必要時) / 貸方: 資産科目`（利益なら売却益を貸方）

> 詳細・数値例は[`daily-activities/examples-of-daily-activities.md`](../daily-activities/examples-of-daily-activities.md)を参照。

## 消費税（基礎）

- 税抜処理：本体価額を科目、消費税は「仮払消費税」等に分ける（後日相殺）
- 税込処理：総額を科目で処理（簡便・小規模向け。原則税抜が望ましい）
- 本ページでは詳細割愛。将来、課税方式ごとの章を追加予定。

## 典型仕訳テンプレ（抜粋）

| 取引 | 借方 | 貸方 |
| --- | --- | --- |
| 家賃を振込で支払 | 地代家賃 | 普通預金 |
| 電話代をクレカで支払 | 通信費 | 未払金 |
| クレカ引落 | 未払金 | 普通預金 |
| 交通費を現金で支払 | 旅費交通費 | 現金 |
| 事業用に自腹入金 | 普通預金 | 事業主借 |
| 事業口座で私費を支払 | 事業主貸 | 普通預金 |
