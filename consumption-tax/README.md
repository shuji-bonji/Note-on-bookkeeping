# 消費税の実務

個人事業主・フリーランスのための消費税実務ガイドです。
インボイス制度への対応、課税事業者の判定、納税額の計算方法などを解説します。

## このセクションの内容

| ドキュメント | 内容 |
|:---|:---|
| [消費税の基礎知識](./overview.md) | 消費税の仕組み、課税対象、納税義務の判定 |
| [課税事業者と免税事業者](./taxable-vs-exempt.md) | 免税の条件、届出手続き、メリット・デメリット |
| [インボイス制度](./invoice-system.md) | 適格請求書の要件、経過措置、登録手続き |
| [消費税の計算方法](./calculation-methods.md) | 本則課税・簡易課税・2割特例の比較 |
| [消費税関連の仕訳例](./journal-examples.md) | 税込経理・税抜経理の具体的な仕訳パターン |

## 想定読者

- インボイス登録を検討している免税事業者
- 課税事業者になったばかりのフリーランス
- 消費税の仕組みを基礎から理解したい人
