# 月次締めチェックリスト（Closing Checklist）

月末に試算表を作成した後、数値の整合と実在性を確認するためのチェックリストです。誤りや未処理を早期に発見し、翌月へ正確に引き継ぎます。

> [!TIP]
> 目的 → チェック → 修正 → 記録（メモ・証憑）→ 引継の順で進めると漏れが減ります。

## 1. ベース整合

- [ ] 借方合計＝貸方合計（試算表）
- [ ] 仕訳の未承認・未分類がゼロ
- [ ] 期首残高と前月末残高の一致（科目別）

## 2. 現金・預金の照合

- [ ] 現金出納帳残高＝実在現金（カウント済）
- [ ] 普通預金残高＝通帳残高（未達一覧付き）
- [ ] クレジットカード：未払金残高＝カード明細の未払合計
- [ ] 手数料・利息の記帳漏れなし（振込・口座維持手数料、受取利息など）

## 3. 売掛金・買掛金（債権債務）

- [ ] 取引先別売掛金一覧の合計＝試算表の売掛金
- [ ] 取引先別買掛金/未払金一覧の合計＝試算表の買掛金/未払金
- [ ] 入金消込・支払消込に未処理なし（相殺取引は摘要で明記）
- [ ] 長期滞留（売掛・買掛）の注記と次アクション（督促/与信/支払計画）

## 4. 経過勘定・月次仕訳

- [ ] 減価償却の計上（固定資産台帳と一致）
- [ ] 前払・未払・未収・前受の計上と妥当性（明細・契約根拠）
- [ ] 定期費用（家賃/サブスク/光熱費/通信）の計上漏れなし
- [ ] 立替・仮払の解消状況（保留はToDo化）

## 5. 在庫・仕入（必要な事業のみ）

- [ ] 期末在庫の把握（実地棚卸 or 簡易把握）
- [ ] 仕入と荷造運賃の区分（販売費と製造原価の線引き）
- [ ] サンプル・ノベルティ等の扱い（販促費/広告宣伝費の検討）

## 6. レポートとメモ

- [ ] 主要KPI（売上・粗利率・経費率・利益・現預金）を記録
- [ ] 差異原因のメモ（誰が見ても再現できる記述）
- [ ] 翌月の課題・締め日・担当をToDo化

## 7. よくあるエラーと対処

- 預金が合わない: 未達/重複/未記帳を洗い出し。月初数日の入出金も確認
- 売掛残が合わない: 請求書金額の税込/税抜の混在、値引・相殺の記帳漏れ
- クレカ二重計上: 利用時の未払計上＋引落時の経費再計上ミス → 引落は未払金の消込
- 振替ミス: 科目の左右取り違い → 仕訳の「増減する勘定」を先に決める
- 消耗品と備品の混同: 10万円基準と耐用年数で判定。方針を統一

## 8. 最終化

- [ ] 月次ロック（会計ソフトの期間ロックを推奨）
- [ ] 月次フォルダへ証憑・レポートを保存（命名規則に従う）
- [ ] 関係者（税理士・パートナー）へ共有
